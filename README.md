# Mémoire LiDAR HD — bassin du Vatancul

Dépôt technique associé au mémoire de Master 2 **« Évaluation du LiDAR HD de l’IGN par cas d’usage en SIG 3D »**.

Ce dépôt rassemble les principaux scripts, notebooks archivés, éléments méthodologiques et fichiers d’environnement utiles à la reproductibilité du travail.

## Contenu

- `scripts/benchmarks/` : scripts de comparaison et de rasterisation LiDAR ;
- `notebooks/archive/` : notebooks de travail conservés à titre d’archive ;
- `docs/` : éléments méthodologiques ;
- `environment/` : dépendances et versions documentées ;
- `data/` : références vers les principales sources de données externes.

## Données

Les données LiDAR HD brutes et les autres jeux de données volumineux ne sont pas redistribués dans ce dépôt. Les principales sources institutionnelles sont indiquées dans `data/SOURCES_EXTERNES.csv`.

## Utilisation

Les scripts sont fournis comme support technique du mémoire. Certains nécessitent d’adapter les chemins de fichiers, les environnements SIG ou les paramètres au poste utilisé.
