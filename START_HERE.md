# Publication rapide sur GitHub

## Méthode la plus rapide
1. Installez **Git** et **GitHub CLI (`gh`)** si nécessaire.
2. Double-cliquez sur `CREER_DEPOT_GITHUB.bat`.
3. Saisissez le nom du dépôt sous la forme `UTILISATEUR/NOM_DU_DEPOT`.
4. Connectez-vous dans le navigateur si GitHub le demande.
5. Le dépôt est créé et envoyé automatiquement.

Si le dépôt GitHub existe déjà, utilisez `ENVOYER_VERS_DEPOT_EXISTANT.bat`.
